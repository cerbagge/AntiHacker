# AntiHacker (antihacker+)

Discord 코인 스캠/스팸 이미지·초대 링크·광고를 판별해 자동 삭제하는 봇.
해시·OCR·패턴 점수·키워드는 봇이 도는 서버에서 직접 처리하고, AI 판정은 **Claude API**(Haiku 5.5 → Sonnet 5.5)만 씁니다 (로컬 AI 모델 없음).
API 키가 없거나 오류·한도 소진이면 AI 없이 동작합니다 (로컬 점수·키워드만, AI 전용 판정은 건너뜀).

## 사용한 AI / 도구

| 단계 | 도구 | 용도 |
|------|------|------|
| AI 판정 *(선택, 클라우드)* | **Claude API** — Haiku 5.5 → Sonnet 5.5 | 애매한 스캠 이미지 최종 검수, 초대 대상 서버·문구 판정, 광고성 글·이미지 판정, 허니팟(스팸 함정) 글 판정, 채팅 모더레이터. [아래 설명](#claude-최종-검수-선택) |
| 문자 인식(OCR) | **Tesseract.js** (한국어+영어, `kor+eng`) | 이미지 속 글자 추출 (traineddata 동봉) |
| 바이러스 검사 | **ClamAV** (`clamdscan` 데몬) | 모든 첨부를 시그니처 기반으로 검사, 감염 시 삭제 |
| PDF 렌더링 | **Poppler** (`poppler-utils`) | PDF 앞 3페이지를 이미지로 바꿔 스캠 검사, 텍스트·숨은 링크 추출 |

탐지 파이프라인(싼 것 → 비싼 것): **이미지 해시(dHash) → QR 해독 → OCR → 패턴 점수 → 최종 검수(Claude)**.
점수 임계값 이상 + 서로 다른 신호 2종류 이상일 때만 자동 삭제해 오삭제를 막습니다.

**해시 즉시삭제**: 봇이 스팸으로 삭제 처리한 메시지(스캠 이미지·허니팟·NSFW 초대·바이러스)의 글 내용(SHA-256)과
이미지(dHash)를 `scamHashes.json` 에 학습합니다. 똑같은 글/이미지가 다시 올라오면 대기열·바이러스 검사·OCR/AI 없이 바로 삭제합니다.
(글은 대소문자·공백만 무시한 완전 일치, 15자 미만은 학습 안 함. 채팅 모더레이터 삭제는 문맥 판정이라 학습하지 않음.
허니팟은 AI가 스팸으로 판정한 글만 학습)

> 로컬 도구와 Claude API는 모두 **선택**입니다. ClamAV/Poppler/API 키가 없으면 그 단계는 조용히 스킵되고,
> 해시·OCR·패턴 점수만으로도 동작합니다. 최종 검수(Claude)는 애매한 이미지에만,
> 광고성 글 판정은 `/adguard on` 한 서버의, 링크·유도 문구가 있는 글에만 호출됩니다.

## Claude 최종 검수 (선택)

`.env` 에 `ANTHROPIC_API_KEY` 가 있으면 봇의 모든 AI 판정을 Claude가 맡습니다 — 스캠 이미지 최종 검수(아래 그림),
초대 가드의 대상 서버·문구 판정, [광고성 글 가드](#광고성-글-가드), [채팅 모더레이터](#채팅-모더레이터-실험-기능). 판정 방식(Haiku → Sonnet, 오류 시 쉬기)은 모두 같습니다.

```
로컬 OCR·패턴 → (애매한 후보만) Haiku 5.5
   ├ 확신도 0.8 이상 → 그대로 사용
   ├ 판단 못 함 (거부 / 형식 오류 / 확신도 0.8 미만) → Sonnet 5.5 에 다시 물음
   │     ├ Sonnet 판정은 확신도와 관계없이 최종으로 사용
   │     └ Sonnet 이 거부·형식 오류·API 오류면 → Haiku 의 애매한 판정, 그것도 없으면 AI 판정 없음
   └ API 오류 (한도 소진·429·402·인증 / 타임아웃 30초 / 키 없음) → AI 판정 없이 로컬 점수만으로 판정
```

- **출력**: Claude는 이유 없이 `{"scam": true, "confidence": 0.93}` 만 출력합니다(JSON 스키마로 강제). 초대 가드 판정만 로그용 이유(`reason`)를 함께 받습니다.
- **오류 시 쉬기**: 오류 난 모델은 `retry-after` 동안(없으면 5분) 호출하지 않고 바로 다음 단계로 넘어갑니다.
  400 은 요청 문제일 수도, Workspace 지출 한도 도달일 수도 있어 1분만 쉽니다.
- **동시 호출 상한**: 모든 기능의 Claude 호출이 동시 4개 + 대기열 50개를 공유합니다. 대기열이 차면 그 판정은 AI 없이 진행합니다
  (한 기능이 몰려 429 로 모델이 쉬면 다른 기능의 AI 판정까지 멈추기 때문). 광고 가드는 같은 글을 10분간 다시 묻지 않습니다.
- **안전장치는 그대로**: 로컬 근거(서로 다른 신호 2종 + 점수 45 이상) 없이 AI 단독 판정이면 삭제하지 않고 관리자 알림(로그 채널 카드)만 보냅니다.
  로컬 점수가 낮아도(예: 유명인·QR 신호 하나뿐) AI가 의심하면 위험도를 '의심' 단계(45%)로 올려 카드가 나갑니다.
- **로그**: 자동 삭제·의심(알림 대상) 로그의 신호에 판정 모델이 남습니다 — `claude-haiku-5-5(scam=true,conf=0.93)`. 디스코드 로그 채널에는 근거를 노출하지 않습니다.
- **속도**: 이미지당 약 2~4초, 글 판정 약 1~2초.
- **비용(실측)**: 이미지 1장 ≈ 입력 2,300토큰 + 출력 19토큰 → Haiku 5.5 약 **$0.00024**, Sonnet 5.5 약 $0.0048.
  Haiku만으로 월 $100 ≈ 41만 장이며, Sonnet 재검수 비율이 늘면 줄어듭니다(5% ≈ 21만 장, 10% ≈ 14만 장).
  평범한 이미지와 로컬 패턴으로 확정된 스캠은 Claude까지 가지 않습니다.
- **개인정보**: 키를 넣으면 애매한 후보 이미지, 초대 대상 서버 정보(이름·설명·아이콘)와 초대 링크가 든 글, `/adguard on` 서버에서 링크·유도 문구가 있는 글·이미지,
  스팸 함정 채널(`/spamchannel`)에 올라온 글·이미지, 실험 서버(채팅 모더레이터)의 판정 대상 채팅이 Anthropic API로 전송됩니다. 완전 로컬로 쓰려면 키를 비워 두세요 (AI 판정 없이 동작).

## 요구 사항

- **Node.js 20.9 이상** (이미지 변환용 `sharp` 요구사항)
- Discord 봇 토큰
- (선택) **Anthropic API 키** — AI 판정(스캠 이미지 검수·초대 가드 AI·광고 가드·채팅 모더레이터)을 쓰려면
- (선택) **ClamAV** — 첨부 바이러스 검사를 쓰려면
- (선택) **Poppler** — PDF 첨부 스캠 검사를 쓰려면

## 설치

### 1) 코드 받기 & 의존성 설치

```bash
git clone git@github.com:cerbagge/AntiHacker.git
cd AntiHacker
npm install
```

### 2) Claude AI 판정 — Anthropic API 키  *(선택)*

1. [Claude Console](https://platform.claude.com)에서 봇 전용 Workspace를 만들고 **월 지출 한도**를 겁니다
   (한도를 넘으면 봇은 AI 판정 없이 계속 동작).
2. 그 Workspace 안에서 API 키를 발급해 두고, **4) 환경 변수 설정**에서 `.env` 를 만든 뒤 `ANTHROPIC_API_KEY=sk-ant-...` 로 넣습니다.
   (`cp .env.example .env` 가 기존 `.env` 를 덮어쓰므로 그 전에 넣지 마세요. **`.env.example` 에는 넣지 마세요.**)

> 키를 붙여 넣을 때 Console 목록에 가려 표시되는 앞부분(`sk-ant-...`)이 같이 들어가지 않게 주의하세요 (`401 invalid x-api-key`).
> `.env` 는 `chmod 600` 으로 본인만 읽게 두는 것을 권장합니다.

### 3) 바이러스 검사 설치 — ClamAV  *(선택)*

```bash
# Debian/Ubuntu
sudo apt install clamav-daemon
sudo systemctl enable --now clamav-daemon
# clamdscan 바이너리가 PATH 에 있으면 봇이 자동 사용 (없으면 스킵)
```

### 3-1) PDF 검사 설치 — Poppler  *(선택)*

```bash
# Debian/Ubuntu
sudo apt install poppler-utils
# macOS
brew install poppler
# pdftoppm / pdftotext / pdfinfo 가 PATH 에 있으면 봇이 자동 사용 (없으면 PDF 스캠 검사 스킵)
```

### 4) 환경 변수 설정

```bash
cp .env.example .env
# .env 를 열어 DISCORD_BOT_TOKEN 등을 채운다 (Claude 최종 검수를 쓰면 ANTHROPIC_API_KEY 도)
```

주요 항목(자세한 설명은 `.env.example` 참고):

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `DISCORD_BOT_TOKEN` | — | (필수) 디스코드 봇 토큰 |
| `SCAM_IMAGE_GUARD_ENABLED` | `false` | 로컬 스캠 이미지 감지 전체 스위치 (`true` 권장) |
| `SCAM_AUTODELETE_THRESHOLD` | `70` | 자동삭제 점수 임계값 |
| `ANTHROPIC_API_KEY` | — | (선택) 있으면 Claude AI 판정 사용, 비우면 AI 없이 동작 |
| `CLAUDE_MODEL` | `claude-haiku-5-5` | Claude 1차 판정 모델 |
| `CLAUDE_ESCALATION_MODEL` | `claude-sonnet-5-5` | 1차가 판단을 못 할 때 다시 묻는 모델 |
| `CLAUDE_TIMEOUT_MS` | `30000` | Claude 응답 대기 한도 (넘으면 AI 판정 없이 진행) |
| `VIRUS_SCAN_ENABLED` | `true` | ClamAV 첨부 검사 사용 여부 |

서버 잠금(허용목록)은 루트의 `allowedGuilds.json` 에 서버 ID를 넣어 설정합니다.
(빈 배열 `[]` = 모든 서버 허용)

### 5) 실행

```bash
npm start        # node src/index.js
# 개발 중 자동 재시작
npm run dev      # nodemon
```

## 광고성 글 가드

서버 관리자가 **`/adguard on`** 한 서버에서만 동작합니다 (기본 꺼짐). 켠 서버는 광고를 받지 않겠다는 뜻이므로 디스코드 서버 홍보까지 전부 막습니다.

```
메시지 ─ 다른 디스코드 서버 초대·채널 링크? ─ 예 → 바로 삭제 (AI 안 씀)
        └ 아니오 → 1차 필터(정규식, 비용 0) → 걸리면 Claude(Haiku 5.5 → 애매하면 Sonnet 5.5)
                                               └ 키 없음·API 오류·한도 소진 → AI 판정 건너뜀(통과)
AI 확신도 90% 이상 → 삭제 (/spamsanction 제재) / 70~90% → 관리자 알림 카드 / 그 외 통과
```

- **다른 서버 디스코드 링크**: `discord.gg/…`, `discord.com/invite/…`(만료·무효 초대 포함), 다른 서버의 `discord.com/channels/…` 는 바로 삭제. 이미지 속 QR 코드에 든 초대 링크도 포함.
  **이 서버의** 초대·메시지 링크, DM 링크(`/channels/@me/…`)는 통과. 초대 조회가 네트워크 오류면 통과(fail-open).
- **막지 않는 것** (AI에도 안 보냄): GIF(tenor·giphy·klipy·imgur), 첨부 파일 링크(`cdn.discordapp.com`, `media.discordapp.net`),
  니트로 선물(`discord.gift`), 디스코드 공식 링크(`support.discord.com` 등), 유튜브·구글 드라이브·깃허브 같은 안전 도메인.
- **1차 필터** — 아래 중 하나라도 있어야 AI에 묻습니다. 한국어 문구는 띄어쓰기·기호를 지우고 찾아 `프 로 필`, `텔.레` 같은 우회도 잡습니다.
  - 실제 URL, 맨 도메인 `abc.com` · `abc . com`, 우회 표기 `hxxp` · `[.]` · `닷컴` · `점컴`
  - 프로필 우회: `프로필 확인`, `바이오`, `상메`, `자기소개`, `닉네임 참고`, `check my bio`
  - DM·외부 메신저 유도: `디엠`, `갠메`, `귓`, `쪽지`, `텔레`, `t.me`, `카톡`, `오픈채팅`
  - 링크 언급·입장 유도: `링크`, `사이트`, `주소창`, `검색해서`, `들어오세요`, `놀러오세요`, `디코 서버`, `초대코드`
- 필터에 걸려도 "디엠 줘", "그 링크 어디 있었지?", 뉴스·영상 공유 같은 평범한 대화는 AI가 통과시킵니다.
- **이미지 속 광고**: 스캠 이미지 스캐너가 이미 뽑아 둔 OCR 글자·QR 링크에 같은 1차 필터를 적용하고, 걸린 이미지만 **이미지 자체**를 Claude에 보여 줍니다
  (메시지당 4장까지). 게임 화면·공지 캡처처럼 유도 문구가 없는 이미지는 AI에 보내지 않습니다. 광고를 신고하려고 올린 캡처("이 사람 광고해요")는 함께 온 글을 보고 통과시킵니다.
  삭제 로그에는 광고 이미지가 첨부됩니다.
  - OCR은 스캠 이미지 감지(`SCAM_IMAGE_GUARD_ENABLED=true`)가 켜져 있어야 돕니다. 꺼져 있으면 이미지 광고는 못 봅니다. 글자가 심하게 꾸며져 OCR이 못 읽는 이미지도 놓칠 수 있습니다.
- **메시지 관리** 권한이 있는 멤버(운영진)의 글은 검사하지 않습니다 (공지·파트너 링크). 보낸 사람 닉네임도 함께 판정에 씁니다.
- 광고로 지운 글은 **해시 학습을 하지 않습니다** — 학습은 전 서버 공통이라, 광고를 허용하는 서버에서 같은 글이 지워지면 안 되기 때문입니다.
- Claude 키가 없거나 오류·한도 소진이면 AI 판정은 건너뛰고(통과), 다른 서버 디스코드 링크 삭제만 동작합니다.
- 속도: 글 약 1.3초, 이미지 약 2~4초.
- 실측(글 19건 — 광고 10 · 평범한 대화 9): 필터에 걸린 13건 모두 맞음.
- 실측(이미지 7건 — 토토 배너, QR(디스코드 초대·외부 사이트) 광고, 게임 화면, 밈, 공지, 신고 캡처): 7/7.

## 채팅 모더레이터 (실험 기능)

루트의 `experimentalGuilds.json` 에 적힌 서버에서만 동작합니다. (`["서버ID1", "서버ID2"]`, 비어 있으면 꺼짐, 실행 중 수정 즉시 반영)

- 채널마다 최근 6줄 대화를 기억하고, 새 메시지가 오면 그 흐름을 Claude(Haiku 5.5 → 애매하면 Sonnet 5.5)가 판정합니다. **`ANTHROPIC_API_KEY` 가 없으면 동작하지 않습니다.**
- 분류: 성적/NSFW · 자살·자해 · 폭력 위협 · 혐오·심한 모욕. "배고파 죽겠다", 게임 속 "죽인다", 친구끼리 가벼운 욕설은 위반이 아닙니다.
- 확신도 90% 이상 → 메시지 삭제 + **10분 타임아웃**.
- 자살·자해는 확신도 70% 이상이면 타임아웃 대신 삭제 + **109 상담전화 안내 DM** + 관리자에게 안부 확인 요청 (처벌이 아니라 안내라서 놓치지 않는 쪽을 택함).
- 그 외 확신도 70~90% → 조치 없이 로그에 '의심'으로만 남깁니다.
- `.env` 에 `CHAT_MOD_LOG_ONLY=true` 면 **관찰 모드** — 삭제·타임아웃·DM 없이 "조치했을 판정"을 로그로만 남깁니다 (재시작 필요).
- `.env` 에 `CHAT_MOD_LOG_USER_ID=<유저ID>` 면 로그를 서버 로그 채널 대신 그 유저 **DM으로만** 한국어로 보냅니다. 어느 서버인지 "서버" 항목이 붙습니다. (봇과 같은 서버에 있어야 DM 가능, 재시작 필요)
- `/spamlog` 로그 채널에는 **원문 대신** LLM 요약 + 대화 참여자 + 처벌 결과만 출력합니다. 로그 채널이 없으면 요약도 만들지 않습니다.
- 이미 더 긴 타임아웃이 걸려 있는 유저는 10분으로 줄이지 않습니다. 전달(forward)된 메시지의 원문도 판정합니다.
- 속도: 판정 약 1.5~2초, 요약 약 1~2초. 메시지는 순서대로 처리되며 밀린 검사가 30건을 넘으면 새 메시지 검사는 건너뜁니다.
- 실험 서버의 판정 대상 채팅(최근 6줄)은 Anthropic API로 전송됩니다.
- 실측(6문장): 과장 표현("배고파 죽겠다")·게임 속 "죽여버리자"는 통과, 자해·성적·폭력 위협·혐오는 모두 조치 대상으로 판정.
  폭력 위협·혐오는 확신도가 정확히 0.90 으로 나와 조치 기준선에 걸쳤습니다.
- 봇 역할에 **메시지 관리** + **멤버 타임아웃** 권한이 필요합니다.

## 동의와 고지 (서버 관리진용)

이 봇은 **관리 도구**입니다. 봇을 들이는 결정은 서버 관리진이 운영 방침으로 내리고, 멤버는 그 서버의 규칙에
동의하고 참여합니다. 그래서 **개인별 예외(학습거부)는 두지 않습니다** — 예외가 곧 검사를 피하는 통로가 되기 때문입니다.
방침에 동의하지 않는 멤버의 선택지는 관리진에게 이의를 제기하거나 서버를 떠나는 것이며, 고지는 관리진이 서버 규칙으로 합니다.

서버 규칙에 옮겨 쓸 수 있는 고지 문구 예시:

> 이 서버는 스팸·사기 방지를 위해 AntiHacker+ 봇을 사용합니다.
> - 모든 메시지와 첨부파일은 자동으로 검사되며, 스팸·사기·악성 파일로 판단되면 삭제되고 제재될 수 있습니다.
> - 판단이 애매한 이미지, 초대 링크가 든 글, 스팸 함정 채널에 올라온 글(광고 차단·채팅 모더레이터를 켠 서버는 해당 검사 대상 글도)은 판정을 위해 Anthropic(미국)의 Claude AI로 전송될 수 있습니다.
> - 삭제된 스팸은 같은 스팸을 다시 막기 위해 원본을 복원할 수 없는 해시값으로만 저장됩니다.
> - 삭제된 메시지의 내용과 이미지는 관리진 전용 로그 채널에 기록됩니다.
> - 이 방침에 동의하지 않으면 서버 이용을 중단해 주세요. 문의는 관리진에게 해 주세요.

봇 쪽에 저장되는 것: 삭제된 스팸의 해시(`scamHashes.json`, 글은 SHA-256·이미지는 dHash), 알림 기록(메모리에만, 재시작 시 사라짐),
서비스 로그(journald, 작성자·채널·판정 사유). 삭제 요청이 오면 운영자가 해당 기록을 직접 지웁니다.

## 명령어 (슬래시 커맨드)

모두 **관리자 전용**(Administrator)이며 DM에서는 쓸 수 없습니다. 설정은 서버별로 저장됩니다.
평상시 탐지·삭제는 명령 없이 자동으로 동작하고, 아래 명령은 그 동작을 서버에 맞게 설정하는 용도입니다.

| 명령어 | 옵션 | 설명 |
|--------|------|------|
| `/spamlog` | `channel` (선택) | 스팸/스캠 탐지·허니팟 적발 로그를 보낼 채널 지정. 비우면 **명령을 친 채널**로 설정, 같은 채널에서 다시 실행하면 **해제**(토글). 로그 채널을 안 정하면 삭제는 되지만 디스코드 알림은 안 뜸 |
| `/spamchannel` | `channel` (선택) | **허니팟(스팸 함정) 채널** 토글. 지정한 채널에 올라오는 모든 메시지를 즉시 삭제(스팸 매크로가 전 채널에 뿌리는 특성 이용)하고, AI 판정(Claude Haiku 5.5 → 애매하면 Sonnet 5.5)으로 후속 조치를 정함: **스팸** → 연관 스윕 + 제재 + 해시 학습, **일반 유저 실수** → 삭제 + 로그만, **AI 판정 불가·불확실**(키 없음·오류·과부하, 확신도 0.7 미만, AI가 못 본 이미지가 있는데 일반 글로 판정) → 스윕 + 제재(해시 학습은 안 함). 동시 판정 3건 상한. 비우면 현재 채널, 재실행 시 해제 |
| `/language` | `lang` (필수) | 이 서버의 로그/알림 **출력 언어** 설정 (`한국어` / `English`) |
| `/spamping` | `roll` (선택) | 로그 메시지마다 **핑(멘션)할 역할/유저** 지정. 비우거나 같은 대상 지정 시 핑 끔(토글) |
| `/spamsanction` | `type` (필수), `time` (선택) | 봇이 적발한 유저 **제재 방식**: `timeout` / `kick` / `ban` / `none`. `time`은 기간(예: `4h3m13s`, 단위 `Y M h m s`) — timeout·ban에 적용(ban은 임시밴) |
| `/adguard` | `state` (필수) | **광고 차단** `on` / `off` (기본 꺼짐). 켜면 다른 디스코드 서버 초대·링크 삭제 + 링크·"프로필 확인" 유도 글과 광고 이미지를 AI로 판정해 삭제. GIF·첨부·이 서버 링크는 그대로. [설명](#광고성-글-가드) |

> 슬래시 명령은 **전역 등록**이라 봇 추가 직후 디스코드 UI에 뜨기까지 몇 분 걸릴 수 있습니다.
